## 二、为什么这份源对我们重要

| 它的内容 | 对我们的用处 |
|---|---|
| **AI 公仔 3D 列印教學** | 数字人形象 → **实体公仔**：她的 GLB 直接能切片打印（从虚拟到实体的最后一段） |
| 3D列印耗材 / 列印技巧 | 选材（PLA/PETG/樹脂）、支撐、層高、方向 —— 决定打印成败 |
| 机型规格差异表 / 設備保養 | 选机与维护（我们已装 Bambu Studio 生态？待核） |
| 軟體與APP | 切片软件链（Bambu Studio / OrcaSlicer）与我们 ffmpeg/blender 链的衔接 |

**注意口径**：这是**3D 打印（实体制造）**知识，与我们上一步的 **3D 建模/绑定/动画（数字资产）**是两段不同的工序——前者把已建模的模型印出来，后者把形象做出来。两段都要，别混。
