# 安装与运行（GBT小土豆V9）

## 1. Python 依赖（只装 pip 包）
```
python -m venv .venv
pip install -r requirements.txt
```

## 2. 外部程序（不是 pip 包）
```
sudo apt install ffmpeg
docker compose up -d
ollama serve &
```

## 3. 环境变量（绝不入仓）
```
cp .env.example .env
export $(cat .env | xargs)
```

## 4. 起面板 / 跑验收
```
uvicorn panel.server:app --port 8765
python audit/stack_acceptance.py --with-local
```
