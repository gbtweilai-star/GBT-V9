## 一、权威标准与出处（我照它练）

| 标准 | 出处 | 关键要求 |
|---|---|---|
| **glTF 2.0 规范** | https://registry.khronos.org/glTF/ | 网格访问器、**JOINTS_0 / WEIGHTS_0**（蒙皮权重要归一）、skin、animation、材质 PBR 通道 |
| **Blender Manual** | https://docs.blender.org/manual/en/latest/ | 建模/UV/权重/骨骼/导出 glTF 的官方口径 |
| **Tripo 3D 角色检查单** | https://www.tripo3d.ai/blog/3d-character-checklist | 概念→建模→拓扑→UV→绑定→导出 的逐项检查（我们模型的来源方） |
| **Game-Ready Asset Checklist 2026** | https://www.strayspark.studio/blog/game-ready-asset-checklist-blender-2026 | 四边面优先 / **清 n-gon** / 法线 / 删内部面 / **UV 不重叠 + 纹素密度一致 + 岛间距 2–4px** / 三角面预算 |
| **3D 流水线 agent 技能** | https://github.com/gamedev-skills/awesome-gamedev-agent-skills | 工序化：锁定预算→建模(清拓扑/法线/水密)→UV→材质→绑定→权重→动画→LOD→**导出 GLB**→进引擎复核 |

## 二、十道工序 + 每道**可机检判据**（这是我们自己的验收口径）

| # | 工序 | 专业做法 | 机检判据（能自动量的） |
|---|---|---|---|
| 1 | 概念/参考 | 多视图参考、锁定预算（面数/贴图/尺寸） | 有参考图与预算表 |
| 2 | 建模 | 轮廓先行、关节处留**形变环** | 包围盒比例合理（头身比、身高） |
| 3 | 拓扑 | **四边面优先 · 清 n-gon** · 删内部面 · 无退化面 | 三角面数/顶点数/退化面=0/非流形=0 |
| 4 | 法线 | 统一朝外、Shift+N 重算 | 法线朝向一致（无法线翻转） |
| 5 | 多边形预算 | 主角/道具/背景分级 | 三角面数落在分级区间（主角 20k–80k 量级） |
| 6 | UV | **不重叠** · 纹素密度一致 · 岛间距 2–4px | 有 UV 通道 · UV 越界=0 · 重叠面积≈0 |
| 7 | 材质 | PBR 通道与色彩空间一致（baseColor 为 sRGB，normal/rough/metal 为线性） | 材质数 · 贴图存在 · 通道命名规范 |
| 8 | 绑定 | 关节命名规范、rest pose、控制器 | **关节数** · 层级正确 · 有 skin |
| 9 | 蒙皮 | 权重归一、无零权重顶点、形变不穿模 | **WEIGHTS_0 存在且每顶点权重和≈1** · 零权重顶点=0 |
| 10 | 动画/导出 | 循环首尾对齐、变换归零、原点/pivot 合理、LOD | 动画数 · 时长 · 循环误差 · 文件体积 · 变换为单位矩阵 |

## 四、我现在会什么、不会什么（如实，别装）

**已经会（本会话真跑过）：**
```
① Blender headless 导入 GLB + 三点光/相机取景 + Workbench 渲染出图
② stdlib 解析 GLB：节点/蒙皮/关节数/动画数/WEIGHTS_0 通道
③ 批量出图与量测（肤色占比、人形高度、腿脚在画、像素差）
④ 用 ffmpeg 出片（stems 三轨、响度 -14 LUFS、字幕烧入）
```

**还不会（短板，明写）：**
```
① 雕刻与重拓扑（Remesh/Retopo）—— 不会从参考图做出干净四边面模型
② UV 展开与纹素密度控制（Smart UV / 手动接缝）
③ PBR 贴图绘制与烘焙（法线/粗糙/金属/AO 烘焙）
④ 权重刷与形变环调整（Weight Paint、形变测试）
⑤ IK/FK 控制器、面部 Blend Shape（口型与表情的形变目标）
⑥ LOD 生成与引擎内复核（Draw Call/内存画像）
⇒ 这六项是我的真短板；下一段就按六周把它们逐项补上并**各交一个判据**。
```

## 五、六周练法（每周必须交一件可量测的产物）

| 周 | 目标 | 交付判据 |
|---|---|---|
| 1 | Blender 基础操作 + 导出入门 | 导入我们 21 个 GLB 全部成功；导出 1 个规范 GLB（glTF-Validator 零错误） |
| 2 | 拓扑与法线 | 清掉 n-gon 与内部面；报告 n-gon=0、退化面=0、法线翻转=0 |
| 3 | UV 与纹素密度 | UV 越界=0、重叠≈0、岛间距 ≥2px、纹素密度方差达标 |
| 4 | PBR 材质与烘焙 | 通道色彩空间正确；烘焙法线/AO 出图并与原贴图对比 |
| 5 | 绑定与蒙皮 | 关节数≥40、权重归一（每顶点和≈1）、零权重顶点=0、形变测试不穿模 |
| 6 | 动画与 LOD | idle/talk/walk 三支循环首尾对齐；LOD0/1/2 三角面递减且轮廓保持 |

**每周判据都要能机检**——不能机检的，不算学会。
