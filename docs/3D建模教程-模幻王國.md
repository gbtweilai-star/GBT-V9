## 一、它教的定位（一句话）

**这是「为了 3D 列印而建模」的流程课**（不是软件操作课）——原话：本篇重点在示范**设计模型的流程**，让读者有概念；
零基础要先学软件操作再回来看。并且明确点出：**Blender 主要用途是动画，多数教学不講 3D 列印的建模技巧**，所以本文特别强调打印注意事项。

## 二、它的关键口径（我要吸收的六条）

| # | 它的说法 | 对我们的意义 |
|---|---|---|
| 1 | 3D 打印的前提是**先有 3D 图档**（3D 物件档：空间座标 + 体积 + 贴图打包） | 我们的 GLB 就是这种档；打印前要做规范体检 |
| 2 | 取得方式三条：**3D 扫描 / 自己绘制（建模）/ 直接购买** | 我们的真身来自 Tripo（等于扫描+生成）；要能自己修才能印 |
| 3 | 推荐 **Blender + FreeCAD**（自由开源、免费、对业余模型玩家功能过剩）；商业软件（Maya/Rhino/Solidworks/Zbrush/3dsMax）非必要 | 我们已装 Blender ⇒ **工具选型是对的，不用买** |
| 4 | **先设 scene 单位**，否则导出尺寸错，切片时会出现意料之外的问题 | 机检：导出前单位与尺寸必须与成品一致 |
| 5 | **要印多大就直接画多大**（例：身长 10 公分）；缩放会让细节失真（0.3mm 刻线缩小后印不出、放大变水沟） | 机检：包围盒尺寸 = 目标尺寸（mm 级），最小特征 ≥ 可打印下限 |
| 6 | 流程实例（鮟鱇隊隊徽）：UV 球体 → 旋转 90° 缩放到目标尺寸 → **放上视图/右侧视图当参考底图** → 调成椭圓 → 立方体做嘴 → **细分修改器** → **贝兹曲线 + 布林运算**开缝 | 这是我们「建模工序」的可执行范本 |

## 三、把它落成我们的建模工序（可机检）

```text
① 设单位：Blender scene unit = 公制毫米；导出前核对（机检：包围盒 mm 与目标一致）
② 参考底图：正视图 + 侧视图（正交）——机检：存在两张正交参考图
③ 基础体：球体/立方体/曲线（布尔与细分为主要手段）
④ 尺寸=成品尺寸：直接按要打印的尺寸建模，不做最后缩放
⑤ 细节下限：最小特征 ≥ 打印下限（如 0.3–0.4mm，按机型喷嘴）——机检：最小特征尺寸
⑥ 拓扑收尾：细分后清 n-gon / 统一法线 / 删内部面（沿用上一步手册的判据）
⑦ 导出 GLB（+ 可选 STL）：单位、尺寸、朝向、原点正确
⑧ 切片前水密检查：非流形=0、法线朝外、壁厚 ≥ 喷嘴×2
```

## 四、与我们两条工序的关系（不混）

| 段 | 目的 | 关键判据 |
|---|---|---|
| 数字资产（建模/绑定/动画） | 把形象做出来、能动、能出片 | 拓扑/UV/PBR/骨骼/权重/动画 |
| 实体制造（3D 打印） | 把模型印出来 | 单位/尺寸/水密/壁厚/悬垂/支撑 |
| **本篇教程** | 桥接两段：**为打印而建模** | 单位设定 · 按成品尺寸建模 · 最小特征 · 布尔/细分收尾 |
