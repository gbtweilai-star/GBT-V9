## 一、触手（Tentacles）—— 她的手、她的编队

**一句话**：框架里有 **100 根触手**。每根都有自己的**职业**、**账号**、**随身库**，并**绑着代码页**（每页代码归属到某根触手）。她是「一人一岗」的编队，不是一个大模型裸跑。

| 项 | 真身（代码路径） | 现场读数 |
|---|---|---|
| 100 根职业册子 | <code>vaults/agency_tentacles/tNNN-职业.md</code> | 100 根（t001 AI 数据修复工程师 · t002 品牌守护者 · t003 地理学家 …） |
| 编队实时状态 | <code>core/fleet_live.py</code> · 面板 <code>/fleet-live</code> | 100 根 · 统计 {"待命":3,"休息":97} · 真动作点亮：落一条账 ⇒ 状态转「工作」，撤掉**如实回落** |
| 每页代码归属 | <code>core/file_binding.py</code> | 覆盖 **100.00%**（1528/1528）· 双向互反 ✅ · 穿透【路径档】平均 **5ms** |
| 地址空间 | <code>core/tentacle_scale.py</code> | 10^8 地址空间，按需实体化，密钥 HMAC 派生 |
| 骨骼绑定（触手绑骨法） | <code>core/bone_binding.py</code> | 她的模型 22 根骨 / GLB 里 0 动画 ⇒ **驱动在代码侧** <code>core/film_studio.py:297-318</code> |

**怎么用（三步）**

**出错长什么样**：全灰 ⇒ 台账里还没落账，先跑一条真动作（任一 <code>verify_*</code> 都会落账）。

## 二、万能插（Universal Plug）—— 一行插入，驱动任何东西

**一句话**：<code>core/pulse.py</code> 的**插座**机制。**一行**完成「插入 → 驱动 → 回读数」。

| 插座 | 能源 | 干什么 |
|---|---|---|
| <code>process</code> | 本机 CPU + 她的调度 | 真跑命令（**退出码如实回传**） |
| <code>file</code> | 本机 IO | 读/写/探测文件 |
| <code>api</code> | 她金库里的凭据（一次存入·自动注入） | 打外部 HTTP |
| <code>web</code> | 她的眼 + 手（人类级操作） | 浏览器里做事 |
| <code>model</code> | **云插件 neurons / 本地算力** | 模型在**沙盒里跑**，产物带 sha256 |

**怎么调**
~~~python
from core import pulse as P
P.plug_and_run("t011", kind="process", action="run", args={"cmd": ["python", "tools/verify_no_begging.py"]})
P.plug_and_run("t001", kind="model",   args={"prompt": "回两个字：在", "backend": "local"})
~~~
**现场读数**：<code>process</code> → ok=True · 码=0 · 真 stdout；<code>model</code> → 后端 本地ollama · 23.2s · 沙盒 <code>state/sandbox/plug-model-*</code> · 产物 <code>out/model_reply.txt</code>（sha256 76a0399e…）。

**踩过的坑（都修了）**
- <code>process</code> 插座原来没写编码 ⇒ 中文输出 GBK 崩 ⇒ 一律 ok=False 无输出（已补 UTF-8）
- 补完后暴露 <code>cp.stdout.decode()</code>（把 str 当 bytes）⇒ AttributeError（已整块重写）
- 结论：**插座读数必须真**，退出码 1 就是 1。

**装进入口**：<code>GBT小土豆V9-总控台.cmd</code> 在 <code>python -m panel.server</code> 之前并了一条 <code>python tools\plug_boot.py</code>（**原入口一行没动**）——开机即灌记忆、报插座状态、说欢迎语。

## 三、穿透扫描（Cross Scan）—— 找真身 · 查硬编码 · 交叉复核

**一句话**：<code>core/cross_scan_fleet.py</code>（+ <code>scan/</code> 包）。目标文件切 **100 个分片**并行扫，**一条命中必须被 ≥2 根分片交叉复核**才算数。

~~~python
from core import cross_scan_fleet as CS
CS.shards(files, 100)                # 分片
CS.run(n_shards=100, limit_files=N)  # 真扫（落账 state/cross_scan_fleet.jsonl）
~~~
**现场读数**
| 目标 | 读数 |
|---|---|
| 仓内（回归） | 文件 **922** · 命中 **106** · 复核 **106** · 孤证 **0** · 全部 ✅ |
| **仓外**（她的 Sider 扩展，Chrome 目录） | 文件 78 · 有效片 60 · 命中 0 · 29.9s ✅ |
| 检查项 | 硬编码凭据 · 干跑默认 · 永远为真断言 · 空壳返回（噪音按 2 根复核剔除） |

**刚修掉的短板**：<code>shards()</code> 原来硬用 <code>f.relative_to(ROOT)</code> ⇒ **目标在仓外直接 ValueError**（穿透式扫描穿不出工作树）。现改成 <code>_rel(f)</code>：**仓内仍用相对路径（老口径不变），仓外自动改绝对路径**。她的真身就是靠这条才扫到。

**边界**：只扫文本类（.py/.js/.ts/.json/.md）；命中=**线索**，须 2 根复核；孤证不计。
