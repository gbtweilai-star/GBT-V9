# 音乐样板规格（配乐合格线）

> 主人令：**抓电影与音乐的样本作为合格线**。本页=抓到的音乐/配乐规格 + 可机检判据。
> 诚实分栏：**A 已抓到出处** / **B 行业通行值（本轮未逐条核对权威源，标注待核对）**。

---

## A. 已抓到的硬口径

| 项 | 口径 | 出处 |
|---|---|---|
| 短剧开篇留人 | **只有 8 秒**让观众决定留下还是滑走 | 知乎《短剧剪辑技巧——怎么给短剧配乐，音乐音效设计》页描述 |
| 开篇立人物 | **0–15 秒内**主要人物必须出场并立住 | 同上 |
| 单集时长（配乐要对齐） | 竖屏 **60–120 秒**；平台红线 ≤3 分钟；建议 90 秒 | docs/短剧样板规格.md（红果/万众编剧） |

## B. 行业通行值（待核对权威源；先用作起始线）

| 项 | 通行值（起始线） | 怎么机检 |
|---|---|---|
| 成片响度 | 流媒体约 **−14 LUFS**；广播 EBU R128 约 **−23 LUFS** | ffmpeg loudnorm 量 integrated loudness |
| 真峰值 | **≤ −1 dBTP** | ffmpeg ebur128 / astats 量 peak |
| 分轨 | **stems 三轨**：对白(DX) / 音乐(MX) / 音效(FX) | 文件存在性 + ffprobe 音轨数 |
| 音乐段落 | 有**起-承-转-合**（前奏/主题/发展/收束） | 段落标记文件（cue）存在 + 时长覆盖全片 |

## D. 可机检的配乐合格判据（写成一条命令）

```text
python tools/verify_music.py --film render/film/<片名>.mp4 --stems render/film/<片名>-stems/
1. 响度落在目标 ±2 LUFS 内
2. 真峰值 ≤ -1 dBTP
3. stems 三轨齐（DX/MX/FX）且每轨可解码
4. BGM 时长 ≥ 成片时长（不出现尾部静音断裂）
5. 前 8 秒有声音（钩子不静音）
```
