## 二、我们现在的病（对照标杆就很清楚）

| 病 | 现在的做法 | 标杆的做法 |
|---|---|---|
| 一张合成 SVG | avatar_face.character_svg() 整身一次画出 | **分层部件**各自独立（脸/发/眼/嘴/身/衣），各自可动 |
| 每帧重画 | for t: character_svg(...) 逐帧生成 | **参数驱动 + 网格变形**（同一资产随参数形变） |
| 比例错位 | VIEW=(240,470) 半身设计硬撑 1920 ⇒ 脸占一半、腿悬空 | **多机位取景**：全身/半身/特写各有 viewBox 与裁切，资产不变 |
| 剪影态 | 重叠 id 导致 url(#skinG) 失效（已修） | 分层 + 独立 defs，从根上不冲突 |

## 三、照抄的五条（直接落进我们的代码）

1. **分层**：把 character_svg 拆成 6 层（后发/身/衣/手臂/头/面部件），每层独立 id 命名空间（避免再撞 id）。
2. **参数驱动**：定义参数表 PARAMS = {mouth_open, blink, head_yaw, body_sway, brow, expression}；渲染只读参数，不再逐帧硬编码。
3. **多机位取景**：同一资产出 **全身 / 半身 / 特写 / 侧面** 四档（不同 viewBox + 裁切），专门解决脸占一半、腿悬空。
4. **网格变形（渐进）**：先在**衣摆/头发/手臂**三处引入简单网格（3×3 控制点），实现 Inochi2D 那种随动手感；不一步上全网格。
5. **绑定工序当流程**：照 OpenMontage character-rigging 的次序——分件 → 网格 → 参数 → 动作 → **验收图集**（四机位 + 表情表）。

## 三·补：机位分别定阈值（我第一版定错了，实测纠正）

> 实测：全身机位肤色占比仅 **5.85%**（穿深色西装+黑发本就如此）⇒ **全身不该用 12% 这条**。
> 正确口径：**特写**判肤色占比 ≥12%；**全身**判「人形高度 ≥60% + 腿脚在画内 + 存在肤色像素 >0.5%」；**表情表**判 6 张互不相同。

## 四、验收判据升级（机检、可红；写进 tools/verify_avatar.py）

~~~text
① 肤色像素占比 ≥12%        （不再剪影；现读数 5.8%）
② 人形连通域高度 ≥画幅 60%  （不再过小；现在背景占 83%）
③ 腿/脚在画内              （底部 20% 有非背景像素，修正悬空）
④ 四机位图齐               （全身/半身/特写/侧面，各一张）
⑤ 表情表可切               （neutral/focused/fear/angry/happy/transform 六张）
⑥ 分层 id 唯一             （文档内 id 无重复；防再次撞 id 变剪影的回归）
⑦ 口型/眨眼参数真作用       （同参数改 mouth_open，画面像素必须变）
~~~
