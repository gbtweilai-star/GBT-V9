## 1. 工程在哪、怎么起

- 工程根：`C:\Users\ADMIN\Desktop\GBT小土豆V9`（`C:\Users\ADMIN\gbt-potato-v9` 是指向它的 Junction，旧脚本照旧能用）。
- 入口三件：`main.py`（CLI 总装）· `panel/server.py`（总控台）· `tools/selfcheck.py`（落盘自检）。
- 端口：**8800** = 本机 V9 面板实例（`state/panel_current.json` 记 `{"port": 8800}`）；
  `8765` 是另一套（V8）的面板口；`8317` = CLIProxyAPI 网关；`11434` = 本机 ollama；`8088` = Octop 底座（本机未运行）。
- 起服务：`python -m panel.server`。**改过代码要重启**面板才生效（模块级已导入）。

## 2. 首次启动：先配密钥，她才出现

顺序是设计死的：**没配主通道 → 先弹配置闸 → 配完她才出现在右下角**。

- 闸的判据来自 `GET /api/setup/status`：必配 `OPENAI_API_KEY`、`GUI_GRANT_SECRET`（其余可留空）。
- 密钥落点：`state/keys.env`（`state/` 已在 `.gitignore`，权限尽力 0600）。**面板永不回显原文，只给前 4 位掩码**。
- 有「稍后再说」：不配也能用——她的**说/听走本机离线通道**（Windows SAPI 听写 + 台湾神经女声）。
- 想手工配：把 `KEY=值` 写进 `state/keys.env`，重启面板；或设成环境变量（**env 优先于文件**）。

## 3. 她是谁：形象 / 表情 / 声音

| 项 | 真件 | 说明 |
|---|---|---|
| 主视觉（会动） | `state/tripo/render/*.webm`（11 段透明动作，VP9 带 alpha） | idle/wave/bow/turn/salute/armsx/think/nod/shake/shy/cheer |
| 形象档（写实） | `state/tripo/render/front_hero.png` 等 | 影棚写实渲染，**只有静帧、没有动作件** |
| 表情 | `state/tripo/render/face_{curious,fear,angry,happy}.png` | 从设定原图 `ref_character_sheet.jpg` 切出，接 `/api/voice/emotion` 换脸 |
| 声音（默认） | `senses/voice_tw.py`（edge_tts `zh-TW-HsiaoChenNeural`） | **台湾腔女声优先**：优先序 `edge-tw → voicestudio → sapi`，可用 `V9_VOICE_PREFER` 改序 |

**诚实边界**：没有专门的口型件 —— 说话时是呼吸/点头动作 + 声波 + 高光脉冲，页面上如实标了。

## 4. 语音对讲（已跑通）

- 页面入口：`/digital-human/console` 底部语音条；任意页面右下角她的浮窗；`/voice` 老页。
- 链路：浏览器录音 → `POST /api/voice/ptt` → 本机 ffmpeg 转 16k 单声道 → **本机 SAPI 离线听写** → 意图分类 → 执行/作答 → 回话（台湾女声）。
- **音频不出机**：转换与识别都在本机（页面上写着这条口径）。
- 没麦也能用：直接点「说一句」听她出声；或在页面上打字问她。
- 常见故障：
  - 浏览器不给麦 → 页面会提示，并自动可走「本机麦」（`/api/mic/listen`）或打字；
  - `webrtcvad` 未装 → 麦克风按定长切段（功能不受影响，只是切段方式降级）；
  - 听到声音但没字 → 看 `/api/voice/center/status` 的「听写通道」，本机识别器缺失时按页面提示装中文语音包。

## 5. 能力位：看、调、串联

- **看**：`GET /api/panel/capabilities` → 58 行（53 项 Octop 离线能力 + 5 项原生），每行带 `ok/reason/calls/rate`。
- **调一条**：`POST /api/panel/capabilities/{cap_id}/run`（body 即该能力的请求 dict）—— 结果 `ok/output/error` 分开回，并落一行 `skill_calls` 账。
- **串联（能力链）**：
  - 线性链：`POST /api/panel/workflows/chain`，body `{"steps":[{"skill":"brain.intent_split"},{"skill":"..."}]}` —— **上一步的输出自动当下一步的请求体**（引擎新增 `pipe` 字段），显式 `inputs` 可覆盖；
  - 完整 DAG：`POST /api/panel/workflows/run`，body `{"definition":{"nodes":[...],"edges":[["a","b"]]}}`；
  - 护栏（真在挡）：环、非上游 `$ref`、未注册能力、明文凭据一律拒；定义可存 `PUT /api/panel/workflows/{fid}`（乐观锁，冲突返 409）。
- 验收：`python tools/verify_capability_chain.py`（19 条）· `python tools/verify_capability_wiring.py`（10 条）。

## 6. 触手：职业 → 完整 LLM → 自配装备与账号

**① 立专业**（先做这步，再做后面）
- 职业源：`desktop/resources/octop/portable/packages/octop/infra/agents/subagents/library/zh`（agency-agents 官方中文库，**272 条 / 19 个分域**，只读 frontmatter，正文当资料不执行）。
- `python -c "from core import tentacle_profession as T; print(T.catalog()['count'])"` → `272`。
- 指派：`T.assign('t001', '<slug>')` —— 一根触手一个专业（`UNIQUE` 硬约束），凭空造专业被拒。
- 身份是**五元**：profession · tentacle_id · llm_profile · context_namespace · room_id（互不混用）。

**② 每根触手 = 完整 LLM**（独立通道/密钥/配额/记忆）
- 逐触手钥匙：环境变量 `TENTACLE_T001_KEY`，或 `GBT_TENTACLE_KEYS`（JSON），或落盘 `state/tentacle_keys.json`。
- 逐触手模型：`TENTACLE_T001_MODEL`（不设就用编队默认，并如实标 `fleet-default`）。
- 找不到独立凭据 → 回退统一密钥并标 `shared-fallback`；`mode="isolated"` 下**明确不可用**，绝不静默借用别人的钥匙。
- 自己的会话：`sess-<tid>`，回合落 `tentacle_session` 表；自己的记忆：`state/tentacle_memory/<tid>.jsonl`（互不可见，主脑有全量视图）。
- 验收：`python tools/verify_tentacle_llm_identity.py`（16 条，含「两根钥匙指纹不同」）。

**③ 自配装备与账号**
- `core.tentacle_equip.plan('<tid>')` → 按专业算出需要哪些服务位与工具（口径是本仓自定，页面上如实标注）。
- `core.tentacle_equip.equip('<tid>', dry_run=False)`：账号走**独立金库** `data/tentacle_identity.sqlite3`（`claim → provision`，无凭据则本地自签并标注）；装备走工具坞 `tools/_bay`（白名单 + **必须带授权令牌**，没令牌报 `needs_grant`，绝不假装装上）。
- 账号库里**只存 handle/state/env_key/指纹**，凭据值永远只从环境变量读。
- 验收：`python tools/verify_tentacle_equip.py`（14 条）。

## 7. 授权令牌：签一次就能动手

- 签名密钥：`GUI_GRANT_SECRET`（env 优先）→ 否则落 `state/gui_grant.secret`；工单密钥同理落 `state/order.secret`。
  **落盘是为了跨进程一致** —— 否则面板签的令牌触手验不过（「假未授权」），这是修过的真 bug。
- 桌面操控：**带授权就真动手，不带只规划**（`core/action_loop.py`）。
- 验收：`python tools/verify_cross_process_grant.py`（真起子进程签、父进程验，10 条）。

## 9. 清理与退役

- `python tools/clean_junk.py` —— 无主中间件（pytest 临时目录 / 语音中间 wav / `%TEMP%/v9_*`）+ 项目自扫垃圾，**一律送回收站（可还原）**。
- 项目的通用退役口径在 `core/retire.py`（`sweep` / `supersede`），同样走回收站。

## 10. 红线（不是中间商，别去拆）

- `body/net_guard.py` SSRF 出网闸 · `core/gui_perception.py` 截图永不出机 · `core/hooks.py` 防偷懒钩子 ·
  `core/workflows.py` 调研闸 —— 这几条是安全与防自欺的线。
- 转账/付款/删除类动作一律要主人授权；**不绕过反机器人**、不批量开第三方账号（`core/tentacle_identity.py` 头注写死了边界）。
- 中间商（该拆的）与红线（不该拆的）区别就一句：**拆了之后她更能看见、更能动手，且没有多出一个能被伪造的成功**。

## 11. 摆放纪律

`core/capability_map.py` / `core/page_registry.py`，否则面板上看不见它。
