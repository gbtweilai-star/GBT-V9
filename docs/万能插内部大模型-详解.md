# 万能插 · 内部大模型详解（为什么中间商没饭吃）

> 本文只写**仓里真有的东西**：配置、链路、实测读数。凡没实测的一律标「未验」。

---

## 一、她的脑长什么样（三层，逐层兜底）

```
第①层  外部可选脑（付费/免费额度）：Agnes 兼容 OpenAI 协议
        endpoint  https://apihub.agnes-ai.com/v1
        model     agnes-2.5-flash（OpenAI 兼容，改 base_url+key 即换任何厂商）
        key 位置  state/keys.env（**已被 .gitignore 忽略**；仓里 grep 不到明文）
第②层  本地免费脑（零成本兜底）：Ollama
        走万能插的 model 插座调用；本机已装；实测 10–25s/次（比云慢，但**不花钱、不出网、数据不出本机**）
第③层  离线兜底：无脑时**拒动**而不是瞎编
        senses_gate 的硬规矩：无『脑』（没有目标与理由）⇒ 拒动（实测读数：②脑 拒动 ✓）
```

**关键设计**：三层是**同一接口**下的可替换件（`core/brain_v9.py`），谁答的会被如实记下（`谁答的` 字段）—— 不存在「偷偷换模型假装是自己想的」。

## 二、万能插（core/pulse.py）：把万物插成一个动作

```
插座（socket）：process · file · api · web · model
统一入口：plug_and_run(target, *, kind, action, args, timeout, ledger, pulse)
账本：每次插都落 state/pulse.jsonl（谁插的、插什么、成没成、多久）
越界即拒：process 插座有准入名单（python/git/node/cmd/powershell/py）
          名单外的（例：whoami）⇒ {"ok":false,"拒动":true,"原因":"不在准入名单"}（实测 ✓）
```

**意义**：模型、进程、文件、网页、API —— 在框架里都是**同一个动作模型**。换模型不改业务代码：改 `model` 插座的指向即可。

## 三、她不止一个模型：五个专业插座（sider_sockets）

| 插座 | 干什么 | 实测读数 |
|---|---|---|
| **chat** | 对话/推理 | Agnes 通路 **4.4s** |
| **code** | 写代码/改文件 | 走 agent_loop 工具环（fleet_status/read_file/run_cmd/scan_path/gen_code）|
| **hand** | 动手（浏览器/键鼠/UIA） | 全过 `senses_gate`：眼→脑→手→验 四步全绿才放行（瞎子缝 **0**）|
| **create** | 出图/出片/出曲 | 出单集实测：90s · 1080×1920 · stems 三轨 · −14 LUFS |
| **wisebase** | 知识库/记忆检索 | **1.69s** |

外部只露一个门：**`/dh-input`**（其余都在内部；对外不暴露业务面）。

## 五、为什么中间商要哭（逐条摆事实）

| 中间商卖什么 | 她这里是什么 | 差价去哪了 |
|---|---|---|
| **按 token 计费的对话** | 本地 Ollama 免费兜底；要用云也只需一个 OpenAI 兼容 key，**随时换厂商** | 省掉每次调用的抽成 |
| **按席位收费的"数字员工"** | 她的触手地址空间 **1 亿**，在岗 LLM 触手 **100**；触手自带邮箱/开源账户/独立云插件 | 省掉人头费 |
| **绑定的知识库/工作流** | 记忆 150 条 + 契约（`contract/`）+ 证据合同（`core/delivery_gate.py`），全部在本地可读可改 | 省掉订阅费 |
| **"你只能在我们平台出图/出片"** | 免费硬核工具链：ffmpeg 8.1.2 · Blender · ComfyUI · Remotion · edge-tts · whisper · Ollama · Python | 省掉平台抽成 |
| **闭源模型黑盒** | 三层脑 + `谁答的` 审计字段 + 每次调用落账；换模型不改业务码 | 省掉锁定税 |
| **数据要上传才"智能"** | 本地优先：数据不出本机；要出网的动作必须过闸、留痕 | 省掉隐私代价 |

**一句话**：中间商卖的是「访问权 + 计费 + 锁定」；她给的是**同一件事在本地做完**，且每步带证据。

## 六、边界（不吹）

```
· 本地脑比云脑慢（10–25s vs 4.4s）—— 换来免费/离线/隐私
· 克隆语音（真声复刻）**还没就绪**：本机无 TTS/piper/fish-speech/GPT-SoVITS 模型（探针实测 可用=false）
· 外部脑要花钱的额度由主人决定（AI 不代付、不代授权）
· 触手充值（如 5sim）也是主人自己充 —— 框架只给规程与台账
```
