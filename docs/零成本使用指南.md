# 零成本使用指南（没钱也能用智能体）

> 目标：**不租云、不买卡、不订阅**，用你自己这台电脑把 GBT小土豆V9 跑起来，永久 0 成本。
> 有钱也不冲突：想快就接一个 OpenAI 兼容的云脑（一条 base_url + 一把 key）；没钱就用本地脑，**一样闭环**。

---

## 一、最低要求

| 项 | 最低 | 建议 |
|---|---|---|
| 系统 | Windows 10/11 64 位 | 同上 |
| 内存 | 8 GB | 16 GB（跑 7B 更顺） |
| 显卡 | 不需要（核显即可） | 有独显快很多 |
| 磁盘 | 10 GB 空闲 | 20 GB（模型 + 渲染缓存） |
| 网络 | 只在安装时需要 | 装完可离线 |

## 二、三步装好

~~~text
1) 下载：git clone https://github.com/gbtweilai-star/GBT-V9
2) 依赖：pip install -r requirements.txt
   本地模型：装 ollama（https://ollama.com）后执行  ollama pull qwen2.5:3b
3) 启动：双击  GBT小土豆V9-总控台.cmd
   面板：浏览器打开  http://127.0.0.1:8800/fleet-live
~~~

## 三、没有钱怎么「有脑」

| 方案 | 花费 | 速度 | 怎么做 |
|---|---|---|---|
| 本地 3B（起步推荐） | **0** | 约 10–25 秒/答 | 装 ollama 并 ollama pull qwen2.5:3b |
| 本地 7B | **0** | 约 20–40 秒/答 | ollama pull qwen2.5:7b（16G 内存更稳） |
| 云脑（有钱时） | 按量 | 1–5 秒/答 | 配 OpenAI 兼容 provider，写进 state/keys.env（永不入仓） |

**坏 key / 断网怎么办**：她**如实回落本地脑**，并在账上写明「谁答的=local」——不空手、不假装。

## 五、钱包与隐私

- 全部跑在**你自己机器上**；不上传你的文件。
- 密钥只放 state/keys.env（**已在 .gitignore**，绝不入仓、绝不回显）。
- 不绕任何网站的反机器人检测；要用的服务必须是你自己的账号/会话。

## 六、出问题先跑这三条（自检）

~~~text

python tools/verify_plug.py     # 万能插：五插座 + 越界拒动 + 落账
python tools/daily_triage.py    # 全框架红黄体检（缺证据即退出码 1）
~~~
