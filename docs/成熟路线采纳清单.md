## 四、采纳计划（按值排序，我照着做）

1. **量产关卡（G5D）+ 计划指纹** —— 最值钱：防"计划一改还照发"。新建 `core/production_lock.py` + `state/量产关卡.json`。
2. **风格锁 + 美术锁定（brief.md / G3A）** —— 新建 `core/style_lock.py`，落 `state/brief.json`（风格/节奏/每镜模型）。
3. **Animatic（G5C）** —— 分镜图按镜头表硬切成一版预览片（ffmpeg），主人看片再决定。
4. **叙事验收（G4C）+ 送件 lint** —— 用判准列问题镜；提示词编译后先 lint。
5. **队列账本 + 验片包** —— 复用手上账本体系，给影视专用一张表。
6. **端到端编排 + ffprobe 验收** —— `tools/produce_film.py`（幂等/断点续跑）+ `tools/verify_film_end2end.py`（ffprobe 开真文件，六条硬指标）。
7. **无配乐母版** —— 结案时每版另存一份（留二次配乐空间）。

### 「合格」的判定（照抄②的严格度）

~~~text
一条命令：python tools/produce_film.py --script <剧本> --out render/film/<片名>.mp4
六条硬指标：① MP4 ② ≥1920x1080 ③ 时长 ≥ 门槛 ④ 有音轨 ⑤ 有字幕 ⑥ 无配乐母版另存
三工作流全绿：verify_film + verify_post + verify_studio 在同一部片上全过
证据：ffprobe 读数 + 质检报告 + 量产关卡指纹 + 落账
~~~
