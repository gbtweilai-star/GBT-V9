# 短剧样板规格（合格线照这个对齐）

> 主人令：**红果以及各大漫剧/短剧平台上排名作品多的是，选排名的作品做样板**。
> 本页=抓到的**行业真规格**（带出处）+ 我们把「合格」改成可自动判的口径。

---

## 一、抓到的样板规格（真数字，带出处）

| 项 | 规格 | 出处 |
|---|---|---|
| 竖屏短剧单集时长 | **60–120 秒** | 万众编剧网《AI 短剧制作与上线全流程详细要求》2026-05 |
| 竖屏短剧总集数 | **1–100 集** | 同上 |
| 平台硬红线（红果/抖音集团，2026-06-05 起） | **真人剧单集 ≤3 分钟**，超了无法上传 | 搜狐《短剧单集限长时代开启，红果迎来第一批试验者》 |
| 平台建议值 | **单集 1 分 30 秒左右** | 同上 |
| 样板实例 A | 《春和景明》第二季：**114 集**，单集稳在 1 分 30 秒，最长 1 分 59 秒（第60/65集），最短 55 秒（第25/40集） | 同上 |
| 样板实例 B | 《妈妈，别回头，一直跑下去》：**68 集**，很多单集不到 1 分钟，一个场景贯穿好几集 | 同上 |
| 编剧合同通行口径 | 单集 **<3 分钟**，建议 **1 分 30 秒** | 同上 |
| 画幅 | 竖屏 **1080×1920**（9:16） | 平台与样板通行 |

> 诚实标注：**"前 3 秒钩子"** 是行业通行做法，但本轮抓到的来源里**没有给出可直接引用的数字**，故本页只作"待验口径"，不当作硬指标。

## 二、所以我们的「合格」改成这样（对齐样板）

| 维度 | 旧口径（我拍脑袋） | **新口径（照样板）** |
|---|---|---|
| 时长 | ≥3 分钟 | **单集 60–180 秒**（建议 90 秒；超 180 秒不合格） |
| 画幅 | 1080p | **竖屏 1080×1920**（或横屏 1920×1080） |
| 一部 | 一条 MP4 | **一部 = N 集**（样板 68–114 集；我们以 **单集合格** 为第一关） |
| 音轨 | 有音轨 | 有音轨（旁白 + 可选配乐） |
| 字幕 | 有字幕 | 烧字幕 + SRT 文件 |
| 母版 | 另存无配乐母版 | 同（留二次配乐空间） |

## 三、一条命令自动判（这就是"合格"）

~~~text
# 出单集（90 秒，竖屏），并当场 ffprobe 判六条
python tools/produce_film.py --name "样板对齐-S01E01" --clips 3 --target-seconds 90 --aspect vertical

# 出一整部（N 集）：每集都跑六条硬指标；全绿才叫"能生产一部短剧"
python tools/produce_film.py --name "样板对齐" --episodes 12 --target-seconds 90 --aspect vertical
~~~

**合格判据（机检，不合格退出码 1）**：
1. 每集 MP4 存在 2. 竖屏 1080×1920（或横屏 1920×1080）3. 单集时长落在 **60–180 秒**
4. 有音轨 5. 有字幕文件 6. 无配乐母版另存
