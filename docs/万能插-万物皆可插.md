# 万能插 · 万物皆可插，万物皆可控

> **一句话**：任何东西 —— 命令行、文件、网站、云接口、大模型、别人家的浏览器扩展 ——
> 只要你能说出它的**入口**与**能源**，就能用**一行**插上并驱动它：
> **plug_and_run(入口, kind=插座类型, action=动作, args=参数)**。
> 插完**不破坏对方**：只接一条自己的线，把它的能力接过来，对外只露我们自己的口。

---

## 一、插座是什么（万物皆可插的根据）

插座 = 一对定义：

| 字段 | 含义 | 例 |
|---|---|---|
| kind（插座类型） | 用哪种能源驱动 | process / file / api / web / model |
| target（入口） | 插哪里：命令名、文件路径、URL、扩展 ID | python ｜ core/pulse.py ｜ https://… ｜ chrome-extension://… |

**五种插座与能源**（core/pulse.py 的 SOCKET_ENERGY 原样）：

| 插座 | 能源 | 能干什么 | 不干什么 |
|---|---|---|---|
| process | 本机 CPU + 她的调度 | 真跑命令，**退出码如实回传** | 不改对方代码 |
| file | 本机 IO | 读 / 写 / 探测存在 | 不越界读敏感目录 |
| api | 她金库里的凭据（一次存入·自动注入） | 打外部 HTTP | **不绕检测**、不伪造指纹 |
| web | 她的眼 + 手（人类级操作） | 浏览器里真做事（她自己的会话） | 不改网站、不注入脚本 |
| model | 云插件 neurons / 本地算力 | 模型在**沙盒里**跑，产物带 sha256 | 模型不许直接碰盘/网 |

## 二、一行怎么用（完整契约）

~~~python
from core import pulse as P

# ① 命令行（process）：真跑，退码如实
P.plug_and_run("t011", kind="process", action="run", args={"cmd": ["python", "--version"]})

# ② 文件（file）：探测 / 读 / 写
P.plug_and_run("core/pulse.py", kind="file", action="exists", args={})
P.plug_and_run("core/pulse.py", kind="file", action="read",   args={})

# ③ 云接口（api）：凭据自动注入，先过出网安全检查
P.plug_and_run("https://example.com/health", kind="api", action="get", args={})

# ④ 模型（model）：在沙盒里跑，产物带 sha256
P.plug_and_run("t001", kind="model", args={"prompt": "回两个字：在", "backend": "local"})
~~~

**返回字段**：ok · 码（退码）· stdout/stderr · 后端 · 秒 · 沙盒 · 产物（文件+sha256）· 能源。
**铁律**：ok 只认真实结果 —— 退码 1 就是 1，不许粉饰。

### 各插座的动作与参数

| 插座 | action | args | 说明 |
|---|---|---|---|
| process | run | cmd：命令数组或字符串（以 py: 开头按 Python 片段跑） | 走 subprocess，UTF-8，超时可设 |
| file | read / write / exists | text（write 时） | 读回 ≤400 字，写回报字节数 |
| api | get / post / … | url / cred / env / json | 先过 body/net_guard 出网检查；凭据从本地金库取 |
| web | 视适配器 | 由适配器定义（见 core/browser_plug.py） | 走她自己的浏览器会话 |
| model | run（默认） | prompt / backend(local, cloud) / face / tentacle | 在 pulse_sandbox 里跑，产物落 outbox |

## 三、怎么把「任何东西」变成插座（四步法）

| 步 | 做什么 | 例子（我们真做过） |
|---|---|---|
| ① 找入口 | 对方靠什么被驱动：命令名？URL？扩展 ID？文件？ | 本机 ollama 127.0.0.1:11434 → model；CLIProxyAPI 127.0.0.1:8317/v1 → api |
| ② 选插座 | 按能源选：能用 API 就别用浏览器，能本地就别上云 | Sider 的 AI 口 preview.sider.ai/v1/* → api（被 Cloudflare 403 ⇒ **不绕**，改接自有模型作脑） |
| ③ 写适配器 | 把对方动作映射成 action/args，把回执规范化成 ok/读数 | 她的五面插座 core/sider_sockets.py（chat/code/hand/create/wisebase） |
| ④ 落账 | 每次插入/驱动都写账（谁·何时·什么动作·什么读数） | state/plug_boot.jsonl · state/sider_sockets.jsonl · state/agent_loop.jsonl |

### 「万物可控」的关键：三件套

- **门**：动手前必须有新鲜取景 + 决策记录（core/senses_gate.py，缺一步**拒动**）—— 防「瞎操作」「无脑操作」。
- **票**：安全域能力要主人在终端发授权；**AI 不许给自己发授权**。
- **账**：每步落账；报警必须带根因/处置/证据，缺一项算未闭环。

## 四、现场读数（本会话实测 2026-10-10，命令可复跑）

| 插座 | 实测读数 |
|---|---|
| process | ok=True · 码=0 · 真 stdout（dir state 列出 29,391B 的 delivery_gate.jsonl 等） |

| file | ok=True · 存在=True（core/pulse.py） |
| api（探 Sider AI 口） | 无 token → **401**（门在）；带 token → **403 Just a moment**（CF 认指纹）⇒ 不绕 |

## 五、失败长什么样 · 排错表

| 症状 | 真因 | 怎么修 |
|---|---|---|
| ok=False 但无输出 | 插座里 subprocess 没写编码，中文输出解码崩 | 补 encoding=utf-8, errors=replace（已修） |
| AttributeError: str has no decode | 把 str 当 bytes 又 decode 一次 | 统一 text=True，不再手工 decode（已修） |
| 目标在仓外就 ValueError | 扫描/绑定硬用 relative_to(ROOT) | 加 _rel() 健壮键：仓内相对、仓外绝对（已修） |
| 页面 401 / 403 | 401=缺凭据；403=Cloudflare 认指纹 | **不绕检测**：改接自有模型，或要对方 API key |
| 插入成功但没读数 | 没落账 | 每次 plug/run 都写 state/*.jsonl |
