# 免费硬核工具 · 专业学习路线（出片必备）

> 主人令：**做这些的工具全部是最硬核的免费工具；指挥官必须学到专业水平，否则做出来的东西等于白搭**。
> 本页每个工具都写：是什么 · 凭什么硬核 · 免费到哪一步 · **学到专业的判据（可自测）** · 我们用它做什么 · 已踩的坑。

---

## 1) ffmpeg / ffprobe（8.1.2 full build）—— 整条片子的骨架

| 项 | 内容 |
|---|---|
| 是什么 | 命令行音视频全流水线：剪辑/拼接/转码/混音/烧字幕/抽帧 |
| 硬核在哪 | 影视行业与所有 AI 视频管线的**共同底座**，没有它任何管线都落不了地 |
| 免费 | 完全免费开源（LGPL/GPL），本机已装 `ffmpeg -version` → 8.1.2-full |
| 学到专业的判据 | ① 能盲写 `-vf subtitles` 且懂 Windows 路径转义（`C\:/a/b.srt`）② 能解释 `-c copy` 与重编码的取舍 ③ 能用 ffprobe 读出宽高/时长/音轨/码率/字幕轨 ④ 会做 concat 清单与时长对齐 |
| 我们用 | ④ concat 出**无配乐母版** · ⑤ 混旁白+烧字幕出成片 · ⑥ ffprobe 六条硬指标验收 |
| 已踩的坑 | **滤镜路径转义写错 ⇒ 成片步骤直接失败**（已修）；`-shortest` 会把全片截成旁白长度（已修，改 `apad + -t dur`） |

## 2) Blender（VSE + 几何/骨骼）—— 镜头与后期的一体机

| 项 | 内容 |
|---|---|
| 是什么 | 3D/合成/视频剪辑一体；VSE（视频序列编辑器）可直接剪片，也能跑生成式节点 |
| 硬核在哪 | 免费却顶得上付费后期：能绑骨做动画、能合成、能出母版 |
| 免费 | 完全免费开源，本机已装（blender 可调） |
| 学到专业的判据 | ① 会用 VSE 剪一条带音轨的片并导出 ② 会绑骨+权重做 idle/walk ③ 懂渲染色深/帧率/编码参数 |
| 我们用 | 数字人骨骼驱动（`core/film_studio.py` 的 pose 驱动）· 资产净化 · 渲染 |
| 已踩的坑 | GLB 里 **0 个动画** ⇒ 驱动必须在**代码侧**（`arm.pose.bones`），不是靠 glb 自带动画 |

## 3) ComfyUI —— 画面生成的工业化工作台

| 项 | 内容 |
|---|---|
| 是什么 | 节点式生成管线（图像/视频），社区节点极多 |
| 硬核在哪 | 成熟短剧路线的**事实标准**（photoreal-short-drama 就靠它跑 MiniMax H3 节点） |
| 免费 | 本体免费；**要显卡**（成熟路线实测 RTX 3090 24G；无卡可降档或走云） |
| 学到专业的判据 | ① 能搭出"首帧→视频→验片"的节点链 ② 会自定义节点与量化档位 ③ 懂显存与步数的取舍 |
| 我们用 | 对应 V9 的 `core/shot_gen.py`（分镜出图）+ 后续本地生成端 |
| 已踩的坑 | 本机**无 NVIDIA 卡**（7.4G 内存）⇒ 本地高画质生成要降档或走云；我们先用"素材+后期"通路保证能出片 |

## 4) Remotion / HyperFrames —— 图形·转场·字幕的合成层

| 项 | 内容 |
|---|---|
| 是什么 | 用**代码/HTML**做视频合成（Remotion = React；HyperFrames = HTML 合成 + 渲染） |
| 硬核在哪 | 成熟路线（ai-film-skills、MYStudio）都用它做**转场/字幕/数据图形**，可版本管理 |
| 免费 | 开源；注意 Remotion 是 source-available（机构 >3 人需 Company License） |
| 学到专业的判据 | ① 能用组件化方式排出带转场的时间线 ② 能一次渲染多分辨率 ③ 懂与 ffmpeg 的衔接 |
| 我们用 | 烧字幕已有 ffmpeg 通路；转场/图形可接 HyperFrames（本仓已有相关技能与工具） |

## 5) edge-tts —— 免费配音（旁白）

| 项 | 内容 |
|---|---|
| 是什么 | 命令行 TTS，多语种多音色（含台湾腔 `zh-TW-HsiaoChenNeural`） |
| 硬核在哪 | **零付费**拿到接近商用音色；可脚本化批量生成 |
| 免费 | 完全免费（本机已装 ✓） |
| 学到专业的判据 | ① 会按角色选音色与语速 ② 会切句控制停顿 ③ 知道要联网 |
| 我们用 | 出片第②步：`--voice zh-TW-HsiaoChenNeural` → 旁白 mp3 |
| 已踩的坑 | 旁白太短 ⇒ 片子被截（已改 `apad` 补足时长） |

| 免费 | 开源（本机已装 whisper ✓） |

## 7) ollama —— 本地免费大模型（大脑/编剧/分镜助手）

| 项 | 内容 |
|---|---|
| 是什么 | 本地跑开源大模型（llama/qwen 等） |
| 硬核在哪 | **永久 0 成本**、可离线、隐私不出机 |
| 免费 | 完全免费（本机已装 ✓，11434 在跑） |
| 学到专业的判据 | ① 会选模型档位（3B/7B/Qwen）② 懂上下文与显存/内存压强 ③ 会写系统提示词锁风格 |
