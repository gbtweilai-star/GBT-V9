# 触手自给自足配置规程

> 口径（主人令 2026-10-10）：**一根触手 = 一个开源账户 + 一个邮箱 + 一个独立云插件（freebuff 免费大模型）**
> + 共享虚拟手机验证平台 **https://5sim.net/zh**（**主人自己充值**，所有触手共用）
> + 触手**用自己的邮箱给自己配置** ⇒ **每根触手运行都不吃本机资源，自给自足**。

---

## 一、一根触手要带什么

| 件 | 归属 | 说明 |
|---|---|---|
| 邮箱 | **触手自有** | 登录、收验证码、找回；不用主人的私人邮箱 |
| 开源账户 | **触手自有** | 用于开源仓库/贡献；**不共号**（共号=一挂全挂） |
| 云插件 | **每根一个独立账户** | freebuff：免费大模型额度；跑在云上 ⇒ **不占本机 CPU/显存** |
| 手机验证 | **共享** | https://5sim.net/zh（**主人自己充值**，触手共用一份余额） |
| 钥匙 | 框架派生 | HMAC 派生，**只存指纹**（sha256 前 12 位），不落逐根明文 |

## 二、自给自足的意义（为什么这么配）

1. **不吃本机资源**：模型跑在云插件额度上，本机只做调度 ⇒ 8G 内存的老电脑也能带 100 根。
2. **一挂不连坐**：邮箱/账户/插件各自独立 ⇒ 单根触手被封/限流，其他 99 根照常。
3. **可持续**：免费额度 + 共享验证余额 ⇒ 长期 0 边际成本。

## 三、红线（写死在 core/tentacle_provision.py 里）

- **明文不入账**：密码/密钥只记指纹，账本里搜不到明文。
- **不代充**：5sim 充值属于花钱动作，**必须主人自己操作**（花钱闸）。
- **不绕反机器人**：不用脚本过验证码/人机校验；账号注册必须走平台正常流程。
- **账号必须是主人自己的**：AI 不许自己给自己发授权、不许冒用他人身份。

## 五、怎么逐根配（三步，命令可复跑）

~~~python
from core import tentacle_provision as TP

print(TP.plan(100)["清单"][0])        # 看第一根要带什么
TP.provision("t001",                  # 登记（只写指纹）
             mail="t001@自有邮箱",
             platform="github:t001",
             plugin_account="freebuff:t001",
             secret="（真密钥，只用于生成指纹）")
print(TP.status())                    # 看整体就绪度
~~~
